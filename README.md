# Art Kill System

A 2D pixel-art survival game set in a dystopian world where artists must face an AI that seeks not only to destroy art, but humanity itself.

Developed with **Godot 4** and **GDScript** as a collaborative game development project.

## Gameplay

Art Kill System is a 2D survival game where players must fight against waves of enemies while trying to survive in a dystopian world.

The game combines fast-paced combat with character movement, enemy waves, different enemy appearances, and progression through increasingly difficult encounters.

### Features

* 2D pixel-art gameplay
* Fast-paced survival combat
* Wave-based enemy spawning
* Player health and damage system
* Multiple player states and animations
* Enemy spawning and management
* Ultimate attack

## Technologies

* Godot 4
* GDScript

## Development

Art Kill System idea, was born in my first GameJam, where I work with wonderful people that I call friends now, is one of my first serious projects in game development.

The project was an important step in learning how to build a complete game using Godot, from player movement and combat to enemy management, animations, spawning systems, and gameplay states.

It also helped me gain experience working with **GDScript**, Godot's scene-based workflow, and collaborative game development.
